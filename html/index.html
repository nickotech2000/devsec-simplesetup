Build and run the PKI

Build the PKI (pki_setup)Make the root and intermediate CAs. The owner reads this first. Profiles: PKI for another companyOne PKI per company, with its own settings file.

Certificates

Leaf certificatesMake server, client, code-signing, e-mail and document-signing certificates. Person certificatesCertificates for people, from a JSON list. Office 365 certificatesCertificates for Microsoft Office and Office 365 users. Sign a request (CSR)Sign a certificate request that someone sent you. Sign a CA of a departmentSign the CA request of another department. Make a request (New-PkiCsr)Make a key and a certificate request.

Tools for CDN, web and signing

Export CA certificatesCA files for Cloudflare, Azure, CloudFront and other CDNs; chain from a leaf. Web server configurationnginx and Apache configuration for Ubuntu and RHEL style Linux. Code signingSign your software; set up a build pipeline.

Servers and revocation

Revocation, CRL, OCSP, time stampRevoke certificates and run the CRL, OCSP and timestamp services. The PKI server (Ubuntu)Publish CRL, OCSP and time stamping from a Linux server. PKI server designWhy the server is built the way it is.

Trust kitLet a computer trust your PKI (no keys inside). DevKitOne zip for a developer: trust plus the tools to issue certificates. Transport packageMove the PKI safely in an encrypted .certpacked. Backup and restoreBack up and restore the whole PKI (Windows).
